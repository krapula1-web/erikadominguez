# Erika AI

Aplicación web móvil experimental para conversar con una asistente de IA llamada Erika, inspirada en referencias proporcionadas por el usuario. No representa a la persona real ni implica que sea consciente.

## Desarrollo

- Interfaz web instalable (PWA)
- API `/api/chat` en Vercel
- Configurar `OPENAI_API_KEY` como variable privada en Vercel antes de usar chat real
- No subir fotos, vídeos ni audios personales a este repositorio público. Para proteger privacidad, cambiarlo a privado desde GitHub Settings > General > Danger Zone > Change repository visibility.

## Despliegue

Importar este repositorio en Vercel. Framework: Other; Build Command vacío; Output Directory `public` (si se cambia la estructura, ajustar según corresponda).
